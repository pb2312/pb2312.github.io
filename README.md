# Your Portfolio Site

A clean, print/ledger-inspired portfolio for finance professionals. Built
with plain HTML/CSS — no build tools, no dependencies.

## 1. Customize the content

Open `index.html` in any text editor and replace:
- Name, title, and hero line near the top
- The three project write-ups (swap in your real projects)
- Experience entries
- About text and skills list
- Email and LinkedIn link in the footer

Colors, fonts, and spacing live in `style.css` under `:root` at the top of
the file if you want to adjust the palette.

## 2. Add your resume

Drop your resume PDF into the `assets` folder and name it `resume.pdf`
(replacing the placeholder). The nav bar and footer both link to it already.

## 3. Publish with GitHub Pages (free)

1. Create a GitHub account if you don't have one: https://github.com
2. Create a new repository named exactly `yourusername.github.io`
   (replace `yourusername` with your actual GitHub username — this exact
   naming is what triggers free hosting).
3. Upload `index.html`, `style.css`, and the `assets` folder into that
   repository (drag-and-drop works fine on github.com, or use `git push`
   if you're comfortable with git).
4. In the repo, go to **Settings → Pages**, and under "Source" select the
   `main` branch, then save.
5. Your site will go live in a minute or two at:
   `https://yourusername.github.io`

## 4. Test it

Open the live URL on both desktop and phone, click every link (including
the resume download), and fix any typos before sharing it on LinkedIn or
in applications.
